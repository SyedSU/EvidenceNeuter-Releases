# Shared distribution contract (schema 1)

Catalog: JSON object `schema:1`, `channel:stable`, positive monotonic `sequence`, UTC `expires`, boolean `publicDownloads`, `releaseGate:{status:blocked|approved,reasons:string[],trustConfigured:boolean,signedArtifactsPublished:boolean,windowsAcceptancePassed:boolean,licensesApproved:boolean,authenticodeVerified:boolean}`, `infrastructure` (Hub), and ordered `products` (genesis, lab, bot, academy, flow, council). Strict unknown-field rejection. Availability: planned, development, available, unavailable.

Each entry: id, name, description, requirements:string[], releaseNotes:string[], availability, version (strict x.y.z or null), sourceCommit (40 lowercase hex or null), release (null or {manifestUrl,version,sourceCommit,platform:windows-x64,download:null|{url,size,sha256}}), screenshots [{url,alt}], licenseNotices [{name,url}]. Product additionally saveSchema (positive integer or null), components {runtime,model}; each component null or {version,sourceCommit,licenseNotices}. Hub version target0.3.0; Genesis target0.4.0. Genesis saveSchema4 is confirmed compatibility epoch for new profiles (internal statev4), not State.version. Legacy statev2/v3 imports are read-only; rollback to epoch1 is disallowed. Screenshots/notices may be empty in development; no invented links. Runtime/model versions independently chosen from actual approved build provenance, not inferred from Genesis version.

Available entries require nonnull version/sourceCommit/release; release matches entry version/sourceCommit. Public downloads require authenticated envelope plus approved gate, every gate boolean true, no reasons, available Hub and Genesis, license notices, and Genesis runtime/model provenance. Release manifest URLs: HTTPS github.com/SyedSU/EvidenceNeuter-Releases/releases/download/<immutable-tag>/<asset>. No query/fragment/userinfo/custom port. Website renders buttons only when publicDownloads and approved gate and available; Hub additionally verifies signed metadata and trust. Catalog alone never authorizes executable installation.

Production catalog transport: exact UTF-8 catalog payload Base64 in {payload,signature}; RSA-PSS SHA256 with pinned RSA >=3072 bit public key. Payload expires online; highest accepted sequence preserved. Development catalog is explicitly unsigned and publicDownloads false. Canonical catalog URL to be provisioned only with real protected publication; current absent.

Genesis package payload remains EXACT Hub0.2 schema1: {schema,product,channel,platform,version,sequence,expires,minimumHubVersion,saveSchema,sourceCommit,packages}. Packages exactly game/runtime/model, each {kind,url,size,sha256,files:[{path,size,sha256}]}. Existing envelope {payload,signature}; no new fields allowed. Required executables EvidenceGenesis.exe, llama-server.exe and genesis.gguf and mounted brain/ and model/. Online new release minimumHubVersion0.3.0 only if features require it; existing Hub0.2 fails explicitly rather than silently misparsing. Existing genesis-stable/genesis-stable.json locator retained as signed Genesis manifest, never replaced with catalog. Hub0.3 adds a separately configured signed catalog URL.

Release gate remains blocked until pinned reviewed production keys, protected human-reviewed publication, signed immutable packages and metadata, license approval, Authenticode setup, and genuine Windows acceptance. No releases currently exist. Metadata renewal signs identical packages/version/source with increased sequence and fresh expiry; key recovery requires newly reviewed Hub installer with replacement pinned key, no remote key downloaded alongside metadata.

Hub download metadata is required only for enabled public Hub availability and must exactly match verified signed Hub manifest. Genesis download remains null; signed component manifest authorizes installation. Screenshot URLs must be same-origin root-relative without traversal, or HTTPS approved GitHub distribution URLs.

Signed Hub manifest schema1 payload: {schema:1,product:hub,channel:stable,platform:windows-x64,version,sequence,expires,sourceCommit,minimumHubVersion,minimumWindowsBuild,installer:{url,size,sha256,publisherThumbprint}}. Publisher thumbprint uppercase SHA256 certificate fingerprint64hex; updater must compare against independently configured pin and authentic Windows signer. No publisher pin exists yet.

URL policy clarification: release manifestUrl alone may use stable metadata locators. Package/installer downloads, external screenshots and notices require immutable approved GitHub release tags; reject latest, stable, genesis-stable and hub-stable asset tags. Screenshots/notices may instead use safe same-origin root-relative paths: no percent encoding, backslashes, queries, fragments, empty segments or dot segments. Their schema uses uri-reference. Legacy Genesis stable locator remains supported.
