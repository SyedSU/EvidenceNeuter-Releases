## Ordered milestones

1. Baseline/toolchain/source audit and publication gates: pin dependencies, validate contracts, preserve blocked downloads and separate reviewed source identities from built artifacts.
2. Android text/speech feasibility: arm64 native persistence/runtime cross-builds, Godot bridge, model delivery/hash/notice verification, actual phone inference, lifecycle/memory/thermal evidence. Compiler output alone does not close this milestone.
3. Save/contracts: complete transaction concurrency, stale-state safety, directory ancestry durability and tested recovery on supported platforms; retain corruption evidence and unchanged save epoch unless a reviewed migration is required.
4. Hub and Genesis: finish install/play/save/update/rollback/recovery journey, package identity, offline component reuse, gameplay/touch/accessibility, inspected signed Windows and Android artifacts and genuine device acceptance.
5. Flow and Council: implement README workflows with shared verified local AI, independent data/storage boundaries, export/recovery and both-platform acceptance.
6. Academy: implement the three approved subjects, inspectable learner progress and correction, safe local generation and both-platform acceptance.
7. Lab: implement approved text/audio features, consent and voice-data controls, vetted model/runtime licensing and both-platform acceptance.
8. Bot: implement scoped OAuth and explicit action confirmation, opt-in accessibility with visible status/revocation, safe audit/recovery and both-platform acceptance.
9. Final suite/website: use real product captures, finish responsive/accessibility/performance checks, retain existing Vercel project, produce support/license/privacy/install documentation, then publish only artifacts that meet all applicable gates.

Physical-device results, production publisher identities, protected release approvals, provider credentials and final public artifact checks remain separate prerequisites. Never claim full suite readiness from a cross-build or documentation check. Record dated scoped evidence in RELEASE-STATE.md as milestones advance.
